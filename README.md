## 🚀 Featured Projects

### [Demo-Tashtibet](https://github.com/Abdallah-Anwar3/Demo-Tashtibet)
An Arabic (RTL) progressive web app for managing interior-finishing projects. One codebase serves two experiences: a management dashboard for admins and project managers, and a mobile-first field app for site engineers, plus a client portal.
- Offline-first reports and expenses with a local queue that syncs when the connection returns
- Security enforced in the database with Postgres Row Level Security, not just in the UI
- Budget alerts, push notifications, project timelines, inventory, suppliers and financial reports

`React` `TypeScript` `Vite` `Tailwind CSS` `TanStack Query` `Dexie` `Supabase` `PWA`

### [Tawsal](https://github.com/Abdallah-Anwar3/Tawsal)
An Arabic awareness website for people with hearing disabilities and their families. It covers disability laws (international and Egyptian), early detection of hearing loss, early intervention, and the family's role.

`HTML` `CSS` `JavaScript` `Bootstrap 5 RTL`

### [AURA — AI Therapy Platform](https://github.com/abdallah-gith/AURA-AI-Therapy)
My university graduation project, built as a team. An AI-assisted mental health platform with a conversational therapist, emotion tracking, and a progress dashboard.

`React` `FastAPI` `PostgreSQL` `AI / RAG`
